SOUNDMANAGER RULES
--------------------------------------------------------------------------
- Channels: MASTER, MUSIC, SFX (includes UI), VOICES; persist volumes/mute.
- Browser audio unlock: only start playback after the first user gesture.
- Audio feedback follows command RESULT: rejected -> ui.deny, accepted ->
  ui.accept. Do not play both for one result.
- Randomize voice/sound pools without touching deterministic gameplay RNG.
- Cooldowns/concurrency caps for hover, selection, soldier speech, mutants.
- Loudspeakers use ONE global broadcast voice; multiple towers must not
  overlap five speeches. Broadcast only while a tower actually operates.
- Worker voice: speak when given an order or on a meaningful event, not
  every tick of chopping/repair. Soldier attack lines are rare, not per shot.
- Engine loops: attach to active trucks and clean up when stopped/destroyed.
- Newspaper: reuse ui.open/ui.close until a dedicated paper Foley is added.
- TASK 030: minimal mute/volume access only. Full audio settings UI -> 031.
- Exclude ORIGINAL/, .wav/.mp3 source copies, .DS_Store, and unused assets
  from the release package. Keep license documents outside public/.
- Potential duplicate: worker_return_02 (1).ogg. Inspect/remove only after
  confirming it is really a duplicate; do not auto-load it into the pool.
- Preserve the original loudspeeker_* filenames for now (typo is harmless).
- Licensing: verify redistribution/attribution rules for all audio packs.
